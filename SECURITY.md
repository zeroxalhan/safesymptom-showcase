# Reporting a security concern

Please report suspected security issues privately to
[support@safesymptom.com](mailto:support@safesymptom.com) with the subject
“Security report: SafeSymptom”. Describe the affected feature and safe,
minimal reproduction steps. Do not post exploit details in a public issue.

Do not include passwords, session cookies, access tokens, real health
information, or other people's personal data. If further evidence is needed,
ask for a suitable sharing method before sending sensitive material.

This showcase does not grant permission to test other users' records, bypass
access controls, disrupt the service, or perform automated bulk extraction.
There is no bug-bounty reward or guaranteed response-time commitment.

For personal-data requests, use
[privacy@safesymptom.com](mailto:privacy@safesymptom.com) or the
[Privacy Center](https://www.safesymptom.com/privacy-center).

## Türkçe

Güvenlik şüphelerini “Security report: SafeSymptom” konusuyla
[support@safesymptom.com](mailto:support@safesymptom.com) adresine özel olarak
bildirin. Etkilenen özelliği ve güvenli, asgari tekrar adımlarını açıklayın.
İstismar ayrıntılarını herkese açık paylaşmayın.

Parola, oturum çerezi, erişim anahtarı, gerçek sağlık bilgisi veya başkalarına
ait kişisel veri göndermeyin. Bu tanıtım reposu yetki aşma, başka kullanıcıların
verilerini test etme, hizmeti aksatma veya toplu veri çıkarma izni vermez.
Ödül ya da kesin yanıt süresi taahhüdü bulunmaz. Gizlilik talepleri için
[privacy@safesymptom.com](mailto:privacy@safesymptom.com) veya Gizlilik Merkezi'ni kullanın.
